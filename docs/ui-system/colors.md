# Design System Inventory - Colors

This document defines the formal color palette inventory utilized across all 16 page routing views of **IdeaGPT**.

---

## 🎨 Color Palette Specifications

### 1. Base Canvas Grays
- **Deep Space Background**: `#070709` (Global canvas fill, creating the premium dark mode look).
- **Sidebar & Card Fill**: `#0c0c0e` (Structured layouts, sidebar containers, dialog sheets).
- **Glassmorphic Card Fill**: `#0b0b0d` (Hover cards, metric cards, charts backgrounds).

### 2. Accent & Neon Brand Colors
- **Royal Indigo Primary**: `#4f46e5` (Selected sidebars, main action buttons, focus halos).
- **Glowing Indigo Hover**: `#818cf8` (Primary link selections, chart vectors, neon gradients).
- **Deep Purple Glow**: `#a855f7` (Secondary monetization badges, checklist checkpoints, metrics tags).
- **Vibrant Fuchsia Accent**: `#ec4899` (AI sparkles backgrounds, SVG area chart load fills).

### 3. State Status Accents
- **Completed/Active Green**: `#10b981` (Approved/Merged badges, checked checklist options, active live API status).
- **High Complexity Orange**: `#f97316` (High complexity bar meters, blocked indicators).
- **Destructive/Bottleneck Red**: `#ef4444` (Critical bottlenecks, timeout alerts, issues indicators).
- **Muted Text Gray**: `#71717a` (Inputs placeholders, lowercase subtexts, copyright labels).
